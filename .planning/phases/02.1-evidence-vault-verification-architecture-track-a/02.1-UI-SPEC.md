# Phase 02.1 — UI Design Contract

> Visual and interaction contract for Evidence Vault & Verification Architecture. Generated from ui-ux-pro-max design system rules for Law Enforcement Surveillance Dashboards.

---

## Design System

| Property | Value |
|---|---|
| Tool | shadcn / Tailwind CSS |
| Preset | data-dense-dashboard / Swiss minimalism |
| Component library | Radix UI / custom shadcn primitives |
| Icon library | lucide-react (CheckCircle2, XCircle, ZoomIn, Eye, ShieldCheck, AlertCircle) |
| Font | Inter / Fira Code (data metrics & scores) |

---

## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|---|---|---|
| xs | 4px | Tag padding, badge inline gap, icon gap |
| sm | 8px | Grid gap in evidence card, compact button padding |
| md | 16px | Card body padding, comparison columns gap |
| lg | 24px | Tab section padding, modal padding |
| xl | 32px | Major section breaks |
| 2xl | 48px | Page header separator |
| 3xl | 64px | Full page bottom padding |

Exceptions: none

---

## Typography

| Role | Size | Weight | Line Height |
|---|---|---|---|
| Body | 14px | 400 (Regular) | 1.5 |
| Label / Badge | 11px | 600 (Semibold) | 1.2 (Uppercase, tracking-wider) |
| Metric / Score | 16px | 700 (Bold) | 1.0 (Fira Code font) |
| Heading (Card) | 16px | 600 (Semibold) | 1.3 |
| Display (Page) | 24px | 700 (Bold) | 1.2 |

---

## Color

| Role | Value | Usage |
|---|---|---|
| Dominant (60%) | `#0F172A` / `#1E293B` | Slate dark dashboard backgrounds and panel surfaces |
| Secondary (30%) | `#1E293B` / `#334155` | Evidence cards, comparison panes, borders (`#334155`) |
| Accent (10%) | `#3B82F6` | Primary action buttons, active tab indicators, focus rings |
| Confirmed Badge | `#16A34A` | Confirmed sighting status badge & verification button |
| Rejected Badge | `#DC2626` | Rejected false-positive badge & reject button |
| Unreviewed Badge | `#EAB308` | Amber pending review badge |

Accent reserved for: Primary submit button ("Save Verification"), Active "Evidence Vault" tab pill, Lightbox active zoom handle.

---

## Copywriting Contract

| Element | Copy |
|---|---|
| Primary CTA | "Verify Sighting" / "Confirm Lead" |
| Secondary CTA | "Mark as Rejected" |
| Empty state heading | "No Forensic Evidence Recorded" |
| Empty state body | "Run an AI Vector Search or upload CCTV footage to identify potential sightings for this case." |
| Error state | "Failed to update sighting status. Please verify network connection and try again." |
| Verification confirmation | "Confirm Sighting: Are you sure you want to promote this sighting to a Confirmed Lead for Case {caseNumber}?" |
